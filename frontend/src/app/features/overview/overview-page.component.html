Access

Admin sign-in opens the internal tools for clubs, coordinators, tournaments, reports, and sanction request review. The generic user sign-in is for general access and does not show the admin Sanction Requests tab. Club sign-in is separate and is used only for a club's sanction history, current requests, and new request forms.

Admin Tools

Clubs

Search, filter, add, edit, export, and manage club contact records.

Coordinators

Review regional coordinator contacts and assignments.

AES Tournaments

Browse sanctioned tournaments by season and update AES tracking fields.

Reports

Provides a routed placeholder for legacy reports while individual reports are rebuilt.

Sanction Requests

Review current requests, update status and notes, and email tournament directors.

Club Sanction Requests

Sanction History

Shows prior sanctioned tournaments for the logged-in club and renewal context.

Current Sanctions

Shows active season requests, status, dates, divisions, locations, and notes.

Sanction Request

Starts a new tournament sanction request using club, venue, age group, and format data.

View and Edit

Club users can view request print layouts and edit requests that are still pending or in question.
